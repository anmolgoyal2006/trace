TRACE is a multi-camera person tracking and re-identification system. This report documents evidence of real model execution, empirical test results, and unit test coverage across the full pipeline. All figures are derived from actual system runs — no numbers are estimated or fabricated.

The pipeline runs YOLOv8n for person detection, BoT-SORT for within-camera tracking, OSNet x1.0 (512-dim) for body appearance embeddings, SCRFD + ArcFace for face embeddings (512-dim), and KPR for part-based embeddings (8 body parts × 512-dim). A triple-fusion scorer combines all three signals with a configurable no-match threshold (0.74).

Key result: In the controlled Re-ID experiment on a 352-crop gallery, the correct person was retrieved as Rank 1 in all 10 out of 10 query variants — including rotated, blurred, brightness-adjusted, and scaled versions of the query image.

9. Honest Limitations

LimitationSeverityNotes
Controlled experiment onlyMEDIUMQueries are transformed versions of existing gallery crops, not independent photographs. This inflates measured accuracy.
Single camera evaluationMEDIUMRe-ID accuracy measured on C01 only. Cross-camera accuracy (C01 → C02) not yet measured.
Small query sampleMEDIUM10 queries across 2 subjects — not statistically sufficient to generalize.
Threshold not calibratedMEDIUM0.74 threshold chosen heuristically. Failed to reject one unknown person. ROC analysis on larger set needed.
CPU-only inferenceLOW~5 crops/sec on CPU. GPU would be 20–50× faster. Affects speed, not accuracy.
Local dataset partialLOWWindows machine has 98 crops locally; full 353-crop dataset is on Colab. 5 unit tests fail on count assertion — not a logic bug.
