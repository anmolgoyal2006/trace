# Phase 5 — Query Variant Robustness Experiment
## Tracks 13 and 16

---

## Purpose

Phase 5.3 revealed that Track 29 (the original source track) contains two
visually distinct people under the same track_id (white-shirt person in
frames 155–215; dark-jacket person in frames 270–300).  Track 29 is
therefore not a reliable single-identity evaluation subject.

This experiment tests whether the TRACE Re-ID pipeline correctly retrieves
a clean, visually consistent track when the query is derived from a crop
belonging to that track.  It also tests whether five controlled query-image
transformations (rotation, lighting change, scaling, blur) degrade retrieval
performance.

This is a **controlled robustness experiment on two tracks, not a
statistically sufficient benchmark.**  Results cannot be generalised to
claim overall Re-ID robustness.

## Anti-Leakage Rule

For each experiment the exact source crop is excluded from the gallery
before any similarity is computed.  This prevents a trivial self-match
from being reported as successful retrieval.

| Experiment | Source crop excluded |
|------------|----------------------|
| Track 13 | `dataset/crops_phase3_final/C01_track13_frame0149.jpg` |
| Track 16 | `dataset/crops_phase3_final/C01_track16_frame0073.jpg` |

Gallery size after exclusion: 352 records (353 − 1).

Track 29 query images (`test_query_1*.jpg`) were **not used** in this
experiment and were **not modified**.
