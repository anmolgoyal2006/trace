# Trace

Multi-camera person tracking and re-identification system.

## Structure

- `ai_pipeline/` — Detection, tracking, re-id, cross-camera matching, route reconstruction, prediction
- `backend/` — FastAPI application
- `frontend/` — React UI
- `dataset/` — Videos, camera graph, metadata
- `db/` — SQLite database
- `notebooks/` — Experiments and prototyping
- `docs/` — Documentation
